# Sounds

LDTD plays Minecraft's own sounds at runtime, re-pitched to suit, and ships none of its own. If
you're used to these sounds from elsewhere, here's what they mean in LDTD.

## Raids

Raid sounds play for every player within the territory's radius plus 64 blocks, in the
**Hostile Creatures** volume category.

| When | Sound |
| --- | --- |
| A raid is announced | A low elder guardian curse |
| Each wave arrives | An evoker's summoning, pitched down |
| The Hearth holds, or dawn breaks | The "challenge complete" chime |
| The Hearth falls | A deep blaze death |

## The Hearth and its sprites

| When | Sound |
| --- | --- |
| A sprite places a block | A light, high stone-place |
| A blueprint builds at once (creative) | A stone-place |
| The Hearth levels up | The level-up fanfare, pitched down |
| The Hearth is relit | A fire charge |

## Towers and guards

| When | Sound |
| --- | --- |
| Archer Tower fires | An arrow shot |
| Cannon Tower fires | A short, high explosion |
| A cannon shell bursts | An explosion |
| Frost Tower pulses | Breaking glass, high |
| Flare Tower fires / the flare bursts | A firework launch / a firework blast |
| A tower is upgraded | An anvil |
| Ember Guard hurt / falls | An iron golem's hurt and death |

## The Gloam

| When | Sound |
| --- | --- |
| Gloam idle, hurt and death | A vex, pitched well down |
| A Flicker blinks | An enderman teleport, pitched down |
| A Smother snuffs a light | Fire going out |
| A Dimcaster casts | An illager casting a spell |
| A Dusk Spire is razed | A wither's death, high |
